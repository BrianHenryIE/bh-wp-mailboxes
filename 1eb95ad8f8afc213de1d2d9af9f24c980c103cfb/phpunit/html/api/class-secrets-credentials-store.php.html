4 *
5 * Uses `wp_get_secret()` / `wp_set_secret()` / `wp_delete_secret()` when WordPress core or the activated
6 * feature plugin provides them; otherwise talks directly to a `WP_Secrets_Libsodium_Provider` built from
7 * the API's classes (loaded from vendor by {@see \BrianHenryIE\WP_Mailboxes\Secrets_API_Loader}), so the

13 * which accounts have credentials without revealing addresses.
